# Game-programming-project-Zeyu-Li

This repository contains my Unity game programming coursework project: **Fourfold Accord**.

**Fourfold Accord** is a 2D poker roguelike card game made in Unity. The player uses poker hands to score points, defeat Battles, enter the shop, buy special cards and upgrades, and progress through different Stages.

The project focuses on implementing gameplay systems with C# scripts, including card selection, poker hand evaluation, scoring, Battle progression, shop logic, special card effects, UI interaction, and audio.
